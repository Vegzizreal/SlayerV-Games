ESP32-S3-Touch-AMOLED-1.75C — Home C1.0

This installer puts Home C1.0 on a 1.75C board (32 MB): the Gengar face as the home screen, swipe for the Rim Wheel app list. The installer script and the firmware file are both hosted in this repo (ESP Web Tools 10.4.0, vendored) — nothing loads from anywhere else. This firmware is only for the 1.75C; do not install it on the 1.75-G ball.

  1. Plug the board into this PC with USB and use Chrome or Edge.
  2. Click Connect above and pick the board's serial port.
  3. If the board will not connect because it is reboot-looping: unplug it, hold BOOT, plug it back in while holding BOOT, then connect.
  4. In the install dialog, tick Erase device, then Install. The erase clears whatever wrong firmware the board is running now.
  5. When it finishes, the board reboots to the face. Swipe for the app wheel; double-tap PWR goes home.
