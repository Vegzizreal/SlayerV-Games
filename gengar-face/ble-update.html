👻 Gengar · Bluetooth Update

Send a new face to the charm over Bluetooth. No Wi-Fi, no cable — the file travels phone → charm, directly.

1. Wake the charm in update mode: hold the PWR button while it boots, keep holding about 5 seconds. The face shows update code and a 6-digit number.

2. Tap Connect and pick Gengar. Your phone will ask for that 6-digit code — type the one on the face.

3. When the versions look right, tap Send update and keep this page open until it finishes. The charm restarts itself into the new version.

Not connected.

Update mode only lasts about 5 minutes — if the charm drops off the list, hold PWR at boot again. A failed send changes nothing: the charm keeps running the version it already has.
