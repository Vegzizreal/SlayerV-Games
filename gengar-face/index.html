👻 Gengar Face · Installer

The living Gengar face for the Waveshare ESP32-S3-Touch-AMOLED-1.75C. Install it from your browser — no drivers, no command line.

1. Plug the board in via USB-C (a data cable, not charge-only).

2. Press Install and pick the board's port (USB JTAG/serial debug unit).

3. When it offers to erase, say yes — first install should start clean.

⚠️ Needs Chrome or Edge on a computer (Web Serial). If the board won't connect: hold BOOT, tap power, release BOOT, try again.

After it finishes, press PWR — the face wakes up.
