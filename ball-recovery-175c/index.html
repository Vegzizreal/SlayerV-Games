ESP32-S3-Touch-AMOLED-1.75C — Factory Recovery

This installer puts Waveshare's factory demo firmware back on a 1.75C board (32 MB). The installer script and the firmware file are both hosted in this repo (ESP Web Tools 10.4.0, vendored) — nothing loads from anywhere else, and the firmware's SHA-256 is printed below.

If the board is reboot-looping every few seconds, read this first:

  1. The board has a battery, so unplugging USB does not turn it off and does not stop the loop.
  2. Before you click Connect: press and hold BOOT, and while still holding it, tap PWR once to restart the board. Keep holding BOOT.
  3. Still holding BOOT, click Connect above and pick the board's serial port. The board is now waiting in download mode — the loop is stopped, and you can let go of BOOT. There is no race from this point on.
  4. In the install dialog, tick Erase device, then Install. The erase is what removes the wrong firmware completely. Once install starts, the chip is held by the installer and cannot reboot away.
  5. If the port never appears in the picker, the board was not holding BOOT at the moment it restarted — repeat step 2 and make sure BOOT is already down before the tap on PWR.
  6. When it finishes, the board reboots into the factory demo.

Board not looping? Just plug it in, click Connect, tick Erase device, and Install.
