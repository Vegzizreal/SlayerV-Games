ESP32-S3-Touch-AMOLED-1.75C — Factory Recovery

This installer puts Waveshare's factory demo firmware back on a 1.75C board (32 MB). The firmware file loads directly from Waveshare's official GitHub.

  1. Plug the board into this PC with USB and use Chrome or Edge.
  2. Click Connect above and pick the board's serial port.
  3. If the board will not connect because it is reboot-looping: unplug it, hold BOOT, plug it back in while holding BOOT, then connect.
  4. In the install dialog, tick Erase device, then Install. The erase is what removes the wrong firmware completely.
  5. When it finishes, the board reboots into the factory demo.
