ESP32-S3-Touch-AMOLED-1.75C - Home R1.35

The R line: a from-scratch firmware for the 1.75C board (32 MB) with the same approved look - the face as the home screen, a swipe on the face opens the rim-wheel app list. The installer script and the firmware file are both hosted in this repo (ESP Web Tools 10.4.0, vendored) - nothing loads from anywhere else. This firmware is only for the 1.75C; do not install it on the 1.75-G ball.

  1. Plug the board into this PC with USB and use Chrome or Edge.
  2. Click Connect above and pick the board's serial port.
  3. If the board will not connect because it is reboot-looping: unplug it, hold BOOT, plug it back in while holding BOOT, then connect.
  4. In the install dialog, tick Erase device, then Install. The erase is required when coming from any other line; if in doubt, tick it.
  5. When it finishes, the board reboots to the face. Swipe the face for the app wheel. Double-tap anywhere goes home, triple-tap turns the screen off; double-tap PWR or a two-finger 3-second hold also goes home from anywhere.

Bluetooth updates (from R1.35 on): once this version is on the unit, later R-line updates can arrive over Bluetooth from the update page — arm the window on the unit (wheel → UPDATE → OPEN UPDATE WINDOW), then push from a phone. The first install of R1.35 itself is cable-only: the Bluetooth door exists only from R1.35 up.
