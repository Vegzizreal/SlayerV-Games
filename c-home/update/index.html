VBALL-C — Bluetooth update

For the R-line 1.75C units only (they advertise as VBALL-C and show R-versions on their UPDATE screen). The other product line advertises the same name — this page checks the running version's lineage before it sends anything and refuses a unit that is not R-line.

On the unit: open the wheel, tap UPDATE, then OPEN UPDATE WINDOW. The unit shows a 6-digit code and a countdown — tap Update here right away, and type the code when the phone asks. The window holds while a transfer is running; it closes after about 30 idle seconds.

Not connected.

Recovery

Only for a unit stuck on a bad or half-sent version. Nothing here runs automatically — each action asks first, and a reinstall also needs a confirm on the unit itself (UPDATE → CONFIRM RECOVERY) before anything is written. Both actions need a live connection (tap Update above first).

Connect to the unit first (tap Update above) — recovery options appear here once the unit reports its state.

There is no signature on update images. What protects an update: it travels only over the encrypted, passkey-paired Bluetooth link, the unit checks the image's SHA-256 hash against the declared hash before it commits, and a fresh image must prove itself for about a minute after booting or the unit rolls back to the previous one on its own.
