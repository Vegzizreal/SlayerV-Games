The metal-cased round unit (32 MB). Firmware versions are numbered C1.x.

Live now: C1.4. 2Updateevery updateBluetooth updates after the first install — no cable. Only accepts the unit named VBALL-C. 3Factory Resetrescue onlyWipes the unit back to Waveshare's factory demo. Rule of thumb: normal days only ever need step 1 of each device. The rescue pages exist for bad days and can be ignored the rest of the time.
