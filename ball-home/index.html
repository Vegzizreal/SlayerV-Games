👻 VBALL — Update v4.0

One page, two doors — pick whichever fits the device you're holding.

This build — EVERYTHING: Gengar is home as the sprite body, and the whole rescue line is included — the v2.7 rescue fixes (pages, screen geometry, sampler-polled button), the touch-sleep fix (touch survives screen-off instead of sleeping forever), and the expander power-button support: on this board the physical PWR button now sleeps, wakes, and double-tap-exits the way it should. New in 4.0, the board's remaining hardware wakes up: the real-time clock chip is read at boot and written on every phone sync, so his clock keeps the time even across a full power cut; the SD card slot is live (Settings → SD CARD turns it off and on); and the home census gains a gauges line — battery %, chip temperature, and the card's size.

Bluetooth update (phone) ▾

Send a new face to the charm over Bluetooth. No Wi-Fi, no cable — the file travels phone → charm, directly.

1. Wake the charm in update mode: on Gengar, swipe left to the app page (or tap the APPS tab at the bottom of his ball), tap UPDATE, then tap YES. The purple ring appears and the face shows update code and a 6-digit number. Update mode is only ever opened from that screen — just turning him on never starts it.

2. Tap Connect and pick VBALL. Your phone will ask for that 6-digit code — type the one on the face.

3. When the versions look right, tap Send update and keep this page open until it finishes. The charm restarts itself into the new version.

Not connected.

Update mode only lasts about 5 minutes — if the charm drops off the list, put him in update mode again (swipe left, UPDATE, YES). A failed send changes nothing: the charm keeps running the version it already has.

Connecting also sets his clock from your phone — that is how he knows the time. Since 1.10 this door is how home firmware updates: the new build lands in his spare slot and he restarts into it, and if it ever fails to boot he rolls back to the version that worked. The cable door below is for a first install or a rescue.

Cable update (PC) ▾

The full wired install, straight from your browser — no drivers, no command line. Use it for a first install or to recover a charm that won't update any other way.

1. Plug the board in via USB-C (a data cable, not charge-only).

2. Press Install and pick the board's port (USB JTAG/serial debug unit).

3. When it offers to erase, say yes — first install should start clean.

⚠️ A cable install erases the charm and resets his memory — a Bluetooth update doesn't.

⚠️ Needs Chrome or Edge on a computer (Web Serial). No buttons are needed to flash: the installer resets the board into download mode in software. If the board won't connect, unplug USB, close any other tab or app that might hold the port, plug back in and try again.

After it finishes, press PWR — the face wakes up.
