# SlayerV Games

Playable web builds. Play at
https://vegzizreal.github.io/SlayerV-Games/

| Game | Folder | Play |
|------|--------|------|
| Trap Tycoon | `trap-tycoon/` | [Play](https://vegzizreal.github.io/SlayerV-Games/trap-tycoon/) |
| Vegas Forever Homes | `pupgotchi/` | [Play](https://vegzizreal.github.io/SlayerV-Games/pupgotchi/) |

Each game lives in its own folder as a single self-contained `index.html`.
To update one game, replace only its folder's `index.html` — the others are untouched.

Note: Vegas Forever Homes saves in the browser. Trap Tycoon starts fresh on each visit.
