🧪 Charm Launcher · Step 1

The one-shot bootloader proof: two toy firmwares on the unified 16 MB partition map. TOY-HOME boots by default, asks for the guest once (clean exit), once more (guest crash) — and the board must come home by itself both times. Full script: STEP1-REPORT.md in this folder's source staging.

1. Plug the board in via USB-C (a data cable, not charge-only).

2. Press Install and pick the board's port (USB JTAG/serial debug unit).

3. When it offers to erase, say yes — this image replaces everything on the chip.

⚠️ Needs Chrome or Edge on a computer (Web Serial). No buttons are needed to flash: the installer resets the board into download mode in software — the BOOT button is never used (it is unreachable in the case, by design). After flashing, watch the boot log from the installer's “Logs & Console” view: no button presses are needed for the whole test, it runs itself.

This is a bench proof, not the pet. It writes the whole 16 MB image (bootloader + unified table + both toys); the real face build is a separate installer.
